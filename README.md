[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3):
one funny single-line excuse a developer gives when code breaks in
production, under 200 characters.

## The entry

> It works on my machine, so I shipped my machine to the data center — production is now just my laptop in a rack, and honestly, it's never run better.

## Run it

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` (set
`MAKEFUN_OUTPUT_DIR` to write somewhere else). Python 3 standard
library only; the file is written with no trailing newline.
